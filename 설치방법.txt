RFLUASETUP 0.6.91 BETA 설치 방법

이번 버전의 기본 서보 설정, 저장 경고창, 메뉴 구성은 RELEASE-0.6.88.md를 먼저 확인하세요.
0.6.91의 다중 트림 선택 방식은 RELEASE-0.6.91.md를 먼저 확인하세요. 초록색 서보를 다시 누르면 빨간색 위치 유지로 바뀌며 Override는 계속 ON입니다. OVERRIDE ALL은 세 서보를 모두 초록색으로 선택합니다.
0.6.89는 REAR의 ELEVATOR TRIM 부호만 반전한 수정 버전입니다. FRONT와 서보 Reverse 설정은 바꾸지 않았습니다. RELEASE-0.6.89.md를 확인하세요.
기존 센터 트림 동작과 주의사항은 CENTER-TRIM-0.6.86.md를 참고하세요. 화면 이름과 배치는 이번 버전 안내가 우선입니다.
0.6.85에서는 FULL SETUP → SERVOS → SERVO OVERRIDE의 좌우 화살표 및 각도 입력 오류를 수정했습니다.
================================

중요 안내
- TX16S MK2에서도 사용자가 잠깐 실행·동작을 확인했습니다. 전체 기능·안전성·장기간 사용 검증을 마친 것은 아닙니다.
- 이 프로그램은 아직 완성되지 않은 BETA 테스트 버전입니다.
- 사용자가 하루 동안 집중해 만든 결과물이며, 실제로 장기간 사용한 상태가 아닙니다.
- 현재는 화면에서 설정값을 변경했을 때 값이 FC에 정상적으로 들어가는 수준까지만 확인했습니다.
- 비행장에서 PC가 없을 때 설정값과 상태를 확인하는 보조 용도가 적당합니다.
- 실제 비행 전 PC용 Rotorflight Configurator 2.3.0과 값을 비교하고 안전한 벤치 테스트를 진행하십시오.
- 사용과 설정 변경의 판단 및 책임은 사용자 본인에게 있습니다.

현재 검증 대상
- 조종기: RadioMaster TX16S MK3 및 현재 사용 EdgeTX 환경
- FC: NEXUS Gyro 및 현재 사용 Rotorflight 4.6.x 펌웨어
- 기준 프로그램: Rotorflight Configurator 2.3.0
- 다른 조종기, 화면 해상도, FC 및 펌웨어에서는 동작을 보장하지 않습니다.

설치 순서
1. 조종기 SD 카드의 기존 SCRIPTS 폴더와 FC 설정을 백업합니다.
2. 배포 ZIP의 압축을 PC에서 해제합니다.
3. SD-CARD 폴더 안의 SCRIPTS 폴더를 조종기 SD 카드 최상위에 복사합니다.
4. 최종 파일 경로가 /SCRIPTS/RFLUASETUP/main.lua인지 확인합니다.
5. 기존 /SCRIPTS/RFLUASETUP 폴더가 있다면 백업 후 폴더 전체를 새 버전으로 교체합니다.
6. 구버전 파일과 신버전 파일을 섞어서 덮어쓰지 마십시오.
7. SD 카드를 안전하게 분리하고 조종기를 재부팅합니다.
8. EdgeTX의 시스템 또는 TOOLS 화면에서 RFLUASETUP을 실행합니다.
9. 화면 상단에 FC LINK가 표시되고 하단에 v0.6.33 BETA가 표시되는지 확인합니다.

연결이 안 될 때
- PC Rotorflight Configurator의 USB 연결을 종료합니다.
- FC, 수신기 전원과 텔레메트리 배선을 확인합니다.
- 수신기 프로토콜, UART, 텔레메트리 및 MSP 설정을 확인합니다.
- NO LINK 또는 AUX LIVE READ ERROR가 계속되면 값을 저장하지 마십시오.

안전
- 모터 설정, Throttle Override, Mixer Override를 사용할 때는 모터 전원을 분리하거나 블레이드를 제거하고 기체를 고정하십시오.
- Receiver Protocol, Serial Ports, Telemetry를 변경하면 연결이 끊길 수 있습니다.
- SAVE 전후의 값을 PC Configurator와 비교하십시오.
