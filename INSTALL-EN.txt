RFLUASETUP 0.6.91 BETA Installation
==================================

RFLUASETUP is an unfinished BETA tool developed from the menus and workflow of Rotorflight Configurator 2.3.0. It aims to make as much of the Configurator as practical available through a transmitter Lua interface.

Current scope
- Best suited for checking settings and status at the flying field when a PC is unavailable.
- Unfinished intermediate release: Easy Setup is implemented through servo center setup, not the complete helicopter setup workflow.
- Current changes passed simulated FC, Lua event, rendered-screen and syntax checks; physical aircraft/transmitter validation is still required.
- Read RELEASE-0.6.91-BILINGUAL.md for current features and limitations.
- TX16S MK2: a user briefly checked operation and reports it appears to work. Full feature/safety validation remains incomplete.
- Current test target: RadioMaster TX16S MK3 with its current EdgeTX environment and NEXUS Gyro with the currently used Rotorflight 4.6.x firmware.
- Other radios, screen sizes, FCs, and firmware versions are not guaranteed.

Installation
1. Back up the transmitter SD card and the FC configuration.
2. Extract the distribution ZIP on a PC.
3. Copy the SCRIPTS folder inside SD-CARD to the root of the transmitter SD card.
4. Verify /SCRIPTS/RFLUASETUP/main.lua.
5. Replace the complete old RFLUASETUP folder. Do not mix release files.
6. Restart EdgeTX and open RFLUASETUP from the system or TOOLS page.
7. Confirm FC LINK and v0.6.91 BETA.

Disconnect the motor and remove blades before bench testing. Verify center pulse and rate against your servo manufacturer's specifications before connecting servos. Presets are not universal compatibility guarantees.

Use entirely at your own judgment and responsibility. Compare values with Rotorflight Configurator 2.3.0 and bench-test all flight functions before flying.
